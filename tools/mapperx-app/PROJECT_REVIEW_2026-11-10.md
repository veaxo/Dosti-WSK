# Проверка проекта и выпуск от 10 ноября 2026

Проверены текущие изменения исходников относительно Git HEAD и изменения
field_planner.py относительно комплекта Windows от 5 ноября. Большая часть
разницы в количестве строк field_planner.py относится к Base64-блокам:
код проверялся отдельно от упакованных библиотек и Vault.

## Что изменилось в самом проекте

- DetectX получает чистый кадр робота через /frame.jpg, со старой версией
  vision использует поток и показывает предупреждение о разметке.
- Поворот, зеркало и заполнение кадра применяются единообразно в DetectX
  и vision_aruco.py. Сброс маски сохраняет пустой JSON, чтобы деплой
  действительно убирал старую маску на роботе.
- PitX показывает Python, numpy, OpenCV/ArUco, Java, камеру, свободное место
  и библиотеки робота; есть слепок окружения и подготовка robot_wheels.
- robot_bootstrap.py устанавливает недостающие библиотеки из robot_wheels
  в отдельный пользовательский каталог. При ошибке сохраняет /info.
- Добавлены удалённый пульт, телеметрия, запись заездов, слоты маршрутов,
  сортировщик и счётчик реально распознанных объектов, обновлены одометрия
  и smooth motion. ConstructX умеет использовать новый счётчик.
- Изменены аппаратные назначения: правый мотор — канал 3, Sharp — AIN 1/0,
  соники — DIO 8/9 и 6/7. Концевики лифта отключены в коде; соники
  опрашиваются по очереди. Это существующие изменения владельца,
  при подготовке выпуска они сохранены.

## Что сделано в этой работе

- В корне добавлен MapperX.java: рабочий Java-лаунчер настольного
  приложения, с комментариями к логике и 128 метками в строковых данных
  (8192 невидимых variation-selector символа). Он ищет проект, проверяет
  приложение и передаёт MAPPERX_PROJECT. В программу робота файл не входит.

- Новая копия field_planner.py для приложения создаётся в generated/.

## Состав и ограничения

Mac: готовая Shuffleboard.app для Apple Silicon и macOS 14+.
Windows: обновлённый полностью офлайн-комплект BUILD_WINDOWS_EXE.cmd,
который собирает Shuffleboard.exe на Windows 10/11 x64. Python 3.12,
19 зависимостей сборки, 84 wheel-файла приложения, иконка и полные
установщики WebView2/.NET включены. В этой среде Windows нет:
готовый нативный EXE здесь не получен и его запуск не проверен.

Отдельный переносной пакет включает Python для Windows/macOS и библиотеки
внутри MapperX_offline.py. Основные файлы извлекаются без интернета.

Аппаратная работа моторов, датчиков, камеры и VMX в этой проверке
не испытывалась. Функция PitX «Скачать библиотеки под этого робота»
в существующем коде требует интернет на ноутбуке и запуск из Python-проекта;
в замороженном приложении она явно сообщает об этом ограничении.
Офлайн-компоненты настольного приложения и библиотеки ARM-робота —
разные наборы. Целевой набор robot_wheels определяется окружением VMX.

Запуск Java-лаунчера из корня проекта: `java MapperX.java` (JDK 11+).
Для обычного запуска готового EXE или APP Java не требуется.
