# Shuffleboard — автономная сборка, 5 ноября 2026

Готовы:

- `dist/Shuffleboard.app` — macOS 14+, Apple Silicon, около 1,61 ГБ на диске.
- `dist/Shuffleboard-macOS-arm64.zip` — 1,181,001,135 байт (1.18 ГБ).
- `dist/Shuffleboard-offline-Windows-Mac.zip` — 1,111,775,858 байт (1.11 ГБ).
- Рядом с обоими архивами — `.sha256` для проверки копирования.

**Нативный `Shuffleboard.exe` не собран: на этой машине нет Windows.**
Подготовлен `build_windows.bat`; он должен выполняться на Windows 10/11 x64
Используется встроенный Windows Python 3.12 x64 и локальные инструменты сборки.
На выходе — `dist/Shuffleboard.exe` и `Shuffleboard.exe.sha256`.
Готовый автономный ZIP уже содержит Windows CMD-лаунчер и встроенный Python;
это отдельная поставка, которую можно запускать на Windows без установленного Python.

## Что включено

В .app и в предусмотренную Windows-сборку входит главный файл
`bundle_payload/offline/MapperX_offline.py` — 1 451 647 871 байт.
Внутри него — 84 офлайн-пакета, три Python (Windows x64, Mac arm64/x64),
полные официальные офлайн-установщики WebView2 x64 и .NET Framework 4.8.
Python, pywebview, pynetworktables, NumPy и OpenCV headless также непосредственно
включены в исполняемое приложение. Windows-скрипт собирает pythonnet,
clr_loader, cffi и необходимые DLL. Список импортов проверен по AST основного
кода и DetectX; результаты — `bundle_payload/dependency-audit.json`.

DetectX включает копии `calibrate_hsv.py` и `color_mask.py`, поэтому может
обработать изображение без внешней папки проекта. В этом режиме настройки и
карты пишутся в отдельный рабочий кэш, а не внутрь подписанной .app.
Для изменения/сборки кода робота по-прежнему выбирается папка проекта.

В начале запуска проверяются ОС, разрядность, реальные импорты библиотек,
операция NumPy/OpenCV и SHA-256 встроенных данных. Хеш манифеста включён
отдельно в замороженный Python-код. `/setup/status` выполняет настоящие проверки
и возвращает `checks`, `offline: true` и фактический список `missing`.

Недостающие системные компоненты Windows извлекаются из главного файла,
проверяются по SHA-256 и запускаются без скачивания из сети. .NET Framework
может запросить обычное подтверждение UAC и перезагрузку Windows.
В поставке для CMD/command есть `Verify-Payloads.py`: он проверяет переносимые
Python, wheels и установщики и допускает штатные изменения кода/VAULT при обновлениях.

Кнопка «Офлайн-папка» в VaultX извлекает пакет из приложения в отдельную папку
Downloads и проверяет SHA-256 результата. Существующие папки не перезаписываются.
Исходный `MapperX_offline/` от 30 октября оставлен без изменений.

## Оформление и интерфейс

- Имя приложения, .exe/.app, заголовка окна и страницы: Shuffleboard.
- Оригинальная иконка ярлыка WPILib 2020; источники — `ICON_SOURCE.md`.

- Прокрутка студий; VaultX прокручивается до нижнего лога, PinX — до последнего устройства.

## Комплект для получения EXE на Windows

Готов `dist/Shuffleboard-Windows-EXE-Builder.zip` — примерно 1,07 ГБ.
Он включает исходники проекта, переносимый Windows Python 3.12, все архивы
для автономного payload, системные установщики и колёса инструментов сборки.
Устанавливать Python или подключать интернет на Windows не требуется.

Распакуйте весь архив в короткий путь и запустите `BUILD_WINDOWS_EXE.cmd`.
Дождитесь строки `DONE`. Результат: `tools\mapperx-app\dist\Shuffleboard.exe`.
Консоль остаётся открытой и после ошибки. В готовом EXE включены иконка,
заставка, GUI без консольного окна и автономные компоненты.

Проверены 258 входных файлов по SHA-256, CRC ZIP и полное замыкание 19
зависимостей для CPython 3.12 / Windows x64. Сам PyInstaller на Windows
здесь ещё не запускался. Проверка: `windows-build-kit-verification.json`.
