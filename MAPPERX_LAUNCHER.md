# Запуск проекта через Java

MapperX.java — самостоятельная точка запуска настольного MapperX / Shuffleboard.
Она находится вне src/main/java и не входит в программу робота.

1. Оставьте Shuffleboard.exe в корне проекта либо в tools/mapperx-app/dist.
   На Mac приложение Shuffleboard.app может находиться там же или в Applications.
2. Откройте терминал в папке проекта.
3. Выполните `java MapperX.java` (нужен JDK 11 или новее).

Проверка без запуска окна: `java MapperX.java --check`.
Можно указать пути явно:

```
java MapperX.java --project "C:\Robots\Dosti_WSK" --app "C:\Apps\Shuffleboard.exe"
```

Лаунчер передаёт MAPPERX_PROJECT в приложение, поэтому будет открыт именно
выбранный проект. Отсутствие приложения или файлов проекта показывает ошибку.
Для обычного запуска готового EXE или APP Java не требуется.

В файле есть метки авторства. Они не мешают исполнению программы и не могут
технически запретить человеку или ИИ прочитать исходный текст.
